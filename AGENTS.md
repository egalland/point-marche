# Publication

- À chaque mise à jour, actualiser `APP_VERSION` dans `lib/app-version.ts` pour correspondre au numéro de la prochaine version Sites.
- Tous les numéros de version visibles de l’application doivent utiliser cette constante.
- Créer un commit pour chaque mise à jour, pousser les sources et publier la version avec le workflow Sites.
- Vérifier le numéro de la version sauvegardée avant de publier ; il doit correspondre à celui affiché dans l’application.
