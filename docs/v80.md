# V80 — recherche fournisseur unique

La fiche fournisseur remplace le duo recherche + liste déroulante par une seule recherche nom / Code. Huit résultats maximum sont présentés dans le flux de la page, sans hauteur maximale ni défilement interne. Une recherche trop large invite à préciser le texte.

Sélection au clic ou avec les flèches et Entrée ; Échap ferme les suggestions. Le fournisseur choisi apparaît dans le champ et peut être effacé. La sélection, l’historique du navigateur et la restauration après actualisation sont conservés.

Les styles de cette recherche utilisent une classe propre pour ne pas modifier le sélecteur fournisseur de la page Statistiques.
