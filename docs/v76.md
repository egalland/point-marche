# V76 — fiche fournisseur

Nouvelle page « Fournisseurs » dans la navigation Données et suivi. Le menu déroulant propose l’union des fournisseurs Planner et PURCHASES, avec recherche par nom, code et anciens libellés.

La fiche présente les simulations et leurs états, le dernier montant d’achats sur 12 mois glissants (sans cumul), les variations GLOBAL et pondérées, l’historique graphique, les trames et délais avec tailles d’échantillons, toutes les étapes et commentaires Planner, et les lignes PURCHASES avec pagination.

Rapprochement sur code fournisseur uniquement (espaces extérieurs et casse normalisés, zéros conservés). Un même nom avec deux codes reste deux fiches ; une simulation sans code reste une fiche distincte. Aucun rapprochement Jira par simple présence d’un nom dans le résumé.

La sélection est conservée dans l’URL `?mode=suppliers&supplier=...`, y compris après actualisation. La fiche est une vue des registres existants ; elle ne crée pas de nouvelle copie des données. Les erreurs et chargements des sources sont affichés séparément. Les champs absents restent inconnus.
