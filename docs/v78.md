# V78 — onglets intégrés et navigation par URL

Fournisseurs reste un onglet de l’application Point marché, dans le même menu que Statistiques et Centre d’import. Tous les onglets utilisent un mécanisme de navigation commun.

- Point marché : URL de base ; autres onglets : `?mode=analyst`, `?mode=stats`, `?mode=suppliers`, `?mode=imports`, `?mode=mail`, `?mode=settings`.
- Le menu et les raccourcis internes mettent à jour l’URL sans recharger l’application.
- Actualisation / lien direct : restauration du bon onglet, y compris Mail. Liens historiques `mode=edit` conservés.
- Précédent/suivant : restauration des onglets. La sélection du fournisseur fait aussi partie de l’historique.
- Aucun doublon d’historique pour un onglet déjà ouvert. La sélection fournisseur et les ancres du précédent onglet sont retirées en quittant Fournisseurs.
- Compatibilité avec le fichier HTML autonome : les paramètres changent, pas le chemin du fichier.

Validation : tests de navigation simulant pushState / popstate, retour au brouillon, retour à la sélection fournisseur et restauration après réinitialisation de l’instance. Le rendu visuel navigateur n’est pas vérifié dans cette session.
