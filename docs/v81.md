# V81 — liste déroulante quand la recherche est vide

Le fournisseur se choisit toujours dans un unique champ combiné.

- Champ vide : ouverture de la liste complète au clic/focus, avec défilement et navigation clavier.
- Texte saisi : résultats filtrés par nom / Code, limités à huit et sans défilement interne.
- Effacer le texte revient à la liste complète. Entrée sélectionne, Échap ferme, le clic extérieur ferme aussi.
- La sélection et l’historique de navigation sont conservés.

Validation : TypeScript, 296 tests (dont les deux modes du même champ), compilation Worker et HTML autonome. Rendu visuel navigateur non vérifié dans cette session.
